CASE STUDY / PERSONAL PROJECT

広告レポート作成の自動化

CSVデータの読み込みから検証・集計・レポート生成までを自動化し、 毎回の加工や転記にかかる手間を減らす仕組みを作成しました。

CSVを読み込む → データを検証する → KPIを集計する → レポートを生成する

課題

CSVの手動加工や集計、レポート作成に時間がかかり、転記ミスも起こりやすい。

対応

CSVの取り込み、データ検証、重複防止、KPI集計、レポート生成を自動化。

期待できること

定型作業を減らし、数字の確認や改善検討に時間を使いやすくする。

使用技術

Google Apps Script JavaScript CSV Google Sheets

動作確認について

管理画面で確認したカラム構成をもとに作成したサンプルデータを使用し、 CSVの処理とスプレッドシートへのレポート生成を確認しました。 実際の広告配信データを用いた検証や、運用環境への適用は今後の課題です。
